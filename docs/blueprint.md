# **App Name**: Roblox Script Hub

## Core Features:

- Script Publishing: Allow users to publish their Roblox scripts with descriptions, categories, and tags.
- Script Browsing: Enable users to browse scripts by category, tags, or search keywords.
- Script Details: Display script details, including description, code snippet, author, and ratings.
- Script Rating: Allow users to rate and review published scripts.
- Code Syntax Highlighting: Highlight Roblox Lua code syntax for better readability.

## Style Guidelines:

- Primary color: Dark green (#2E7D32), reflecting Roblox's color scheme.
- Secondary color: Light green (#A5D6A7) for accents and highlights.
- Background color: Light gray (#F5F5F5) for a clean interface.
- Body font: 'Roboto' for readability and modern look.
- Headline font: 'Open Sans' for clear headings.
- Use simple, flat icons related to scripting and Roblox themes.
- Clean and organized layout with clear sections for browsing, publishing, and script details.
- Subtle animations for transitions and feedback, such as highlighting on hover.
